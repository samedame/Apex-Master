# Baseline audit

Starting revision `a635247b0c93e595dd00ea43d92fa400c6783d05`. Before edits, the host Python 3.9 lacked NumPy and pandas. The untouched suite passed 75 tests under Python 3.12, pandas 2.3.3, NumPy 2.2.6, and PyYAML. Historical CSVs, preregistrations, research results, and forward-test records are preserved.
